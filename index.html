About

Jaya Games publishes the board games designed by Jayadev Haddadi. Each game is meant to be simple to learn and rich to play, and we aim to make every one available as a free print-and-play, with more ways to play to follow.

Jayadev is a board game designer and developer who also adapts games for Board Game Arena. Riverbend is the first game from Jaya Games.
